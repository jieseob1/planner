- 기준 리포트: [`RED_TEAM_USABILITY_REPORT_2026-09-02.md`](./RED_TEAM_USABILITY_REPORT_2026-09-02.md)

## 결론

기존 리포트의 RT-01~RT-24는 모두 구현 경로가 생겼고, 핵심 데이터·계획·회고·결과 관리 회귀는 자동 테스트로 확인했다. 특히 계정별 로컬 저장 격리, 사용자에 묶인 ETag, 일정의 절대 날짜 저장, 결과 CRUD와 지표 이력, 실제 다음 주 이월, 기간별 집계, 설정 카드별 오류 복구가 보강됐다.

로컬 운영형 E2E는 랜딩 페이지부터 데스크톱·모바일·키보드·200% 확대, 계정 삭제 후 재가입, 가짜 Google Calendar까지 실제 브라우저로 통과했고 CI에도 필수 게이트로 추가됐다. 동시성·soak·ETag·failover·quota retry, 운영 계약, 마이그레이션 재시작, 복구, 의존성·비밀정보 검사도 통과했다. 추가로 in-app browser의 390px와 320px Today에서 문서 가로 넘침이 없고 00:00~24:00 슬롯, 현재 시각선, 독립 일정 모드와 대화상자 sticky footer가 보이는 것을 확인했다. 다만 **공개 외부 서비스 검증까지 끝난 것은 아니다.** 실제 Google 계정 OAuth 왕복, 공개 도메인의 실제 OIDC 로그인, iOS·Android 네이티브 푸시·딥링크·한글 키보드는 별도의 외부·실기기 검증이 남아 있다.

## 상태 표기

- `구현됨`: 현재 작업 트리에 요구 동작을 처리하는 코드와 테스트 대상 경로가 있다.
- `PASS`: 아래 기록한 자동 테스트를 이 작업 트리에서 실제 실행해 통과했다.
- `부분`: 핵심 로직은 자동 검증했지만 브라우저 레이아웃, 실제 계정 또는 네이티브 환경 검증이 더 필요하다.
- `외부·수동 필요`: 자격 증명, 실제 공급자, 실기기 또는 브라우저 시각 판단이 필요하다.

## 레거시 무날짜 일정 제한사항

V9부터 새 시간 블록은 `block_date`에 ISO 날짜를 저장한다. 반면 기존 MySQL 행의 `block_date`는 원래 의도한 날짜를 데이터만으로 재구성할 수 없기 때문에 `NULL` sentinel로 남긴다. 서버는 이 행을 반복 일정처럼 알림하거나 Google Calendar로 새로 내보내지 않는다.

브라우저의 과거 스냅샷에 `date`가 없으면, 마이그레이션 순간의 **계정 시간대 현재 주 + 기존 `weekOffset`과 요일**로 날짜를 한 번 계산한 뒤 절대 날짜로 고정한다. 이후 주가 바뀌어도 다시 이동하지는 않지만, 최초 계산 날짜가 사용자의 원래 의도와 같았는지는 증명할 수 없다.

따라서 RT-15의 판정은 다음처럼 나뉜다.

- 신규 및 이미 절대 날짜가 있는 일정: 구현됨·자동검증 PASS.
- 날짜 없는 과거 브라우저 일정: best-effort 마이그레이션이며 사용자 확인 필요.
- 날짜 없는 과거 DB 일정: 안전을 위해 알림·내보내기에서 제외되므로, 공개 전 별도 목록/관리자 점검 또는 사용자 재배치 경로가 필요.

이 제한을 해소하기 전에는 “모든 과거 일정 날짜를 무손실 복원했다”고 판단하지 않는다.

## 운영 전 남은 검증

1. 현재 작업 트리에서 통과한 전체 게이트를 최종 후보 커밋과 CI에서 동일하게 재현해 배포 기록에 남긴다.
2. 실제 Google 테스트 계정으로 RT-18의 가져오기·내보내기·수정·삭제·재인증을 수행한다.
3. 공개 도메인과 실제 OIDC에서 RT-19의 로그인·콜백·새로고침·토큰 만료·로그아웃을 수행한다.
4. Today 390px·320px 실화면 확인은 완료했다. 남은 최종 시각 QA에서는 Goals 320px과 실제 충돌 대화상자를 재촬영하고 `scrollWidth`, 포커스 순환, 터치 대상을 기록한다.
5. iOS·Android 실기기에서 한글 IME, 앱 복귀, 뒤로가기, 딥링크, 푸시 권한 허용·거절·로그아웃 해제를 확인한다.
6. 실제 두 OIDC 계정으로 RT-14를 반복하고, 날짜 없는 과거 일정 목록을 사용자와 대조한다.

위 여섯 항목이 끝나기 전 상태는 **기능 구현과 자동 회귀 보강 완료, 외부·실기기 운영 QA 진행 전**으로 본다.
