## 아직 운영자가 준비해야 하는 것

1. **Google Cloud/Firebase**: 운영 프로젝트, OAuth 동의 화면/도메인/최소 scope, 테스트 계정, 클라이언트 자격 증명. 연결→새 일정→변경→삭제→연결 해제→토큰 갱신을 실계정으로 검증합니다. Calendar 변경 webhook은 휴대폰 알림이 아닙니다. [Google 공개 전 scope 검증 안내](https://developers.google.com/identity/protocols/oauth2/production-readiness/sensitive-scope-verification)
2. **실기기 알림**: FCM/APNs 서버·앱 설정과 서명, Android/iPhone에서 권한 거부/허용·앱 종료·15분 전·변경/취소·시간대 이동 검사. 현재 네이티브 HTTPS 게이트웨이 어댑터만으로 공급자 연결이 완료되지는 않습니다. [Firebase Android 설정](https://firebase.google.com/docs/cloud-messaging/android/get-started)
3. **AI 공급자/예산**: 운영자가 모델·키·월 비용 한도를 정한 뒤 테스트 계정의 명시적 동의로 품질·토큰 사용량을 검증합니다. 이번 작업에서 사용자의 실제 기록을 외부 AI에 보내지 않았습니다. 입력/비용이 불확실한 요청은 자동 재시도하지 않습니다.
4. **외부 백업/장애 연락**: 별도 버킷과 최소 권한 자격 증명, 외부 감시 지점, 실제 알림 수신처. 로컬 gzip은 암호화나 오프사이트 백업이 아닙니다. 최신 외부본 복원과 장애/복구 알림 도착을 확인합니다.
5. **앱·결제**: Apple Developer/Google Play Console과 서명·스토어 심사, 사업자·결제 공급자·가격·환불/해지·세금 검토. 현재 무료 웹 베타와 테스트 앱 빌드를 유료/스토어 출시로 표현하지 않습니다.
6. **실사용 베타**: 모집 대상·지원 시간·비공개 지원 창구 결정 후 소규모 초대. 현재는 모집 초안/운영 절차를 준비했으며 초대·외부 게시·광고비 집행을 하지 않았습니다.
